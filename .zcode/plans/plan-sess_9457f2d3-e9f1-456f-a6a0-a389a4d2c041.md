# 页面编辑操作 + 右键菜单 + 工具栏 实现计划

## 目标
为选中页面提供两类操作入口:(1) 编辑工具栏按钮 (2) 右键页面菜单。操作包括:插入空白页、删除、复制、旋转、拆分文档、合并文档、单独保存(导出文件 / 另存为应用内文档)、拖拽重排(已有)。

## 需求确认(已与用户确认)
- 插入空白页:在选中页后插入,尺寸与选中页相同(无选中则A4加末尾)
- 复制页面:在原页后插入副本
- 拆分文档:选中页原地拆分为新文档(左侧文档栏出现新文档,原文档保留剩余页)
- 单独保存:两者都要 -- 选中页导出为PDF文件 + 另存为应用内新文档
- 合并文档:把所有已加载文档合并为一个新文档(在左侧文档栏出现)

## 核心设计决策:Worker 侧用"生成 PDF 字节再重新加载"模式

空白页和复制页需要一个可在 Worker 中按 `sourceDocId + sourcePageIndex` 查到的源 PDF。**最简方案**:新增一个 Worker 操作 `createDocFromPages`,它接收一组页面规格(可来自多个源文档,可包含空白页),用 pdf-lib 构建一个新 PDFDocument 并存入 `docs` Map,返回新的 docId + 元数据。这样:
- 插入空白页 → 创建一个只含空白页的合成文档,在 pages 数组中引用它
- 复制页面 → 创建一个含副本的合成文档,引用其 pageIndex
- 拆分/另存 → 创建含选中页的合成文档,在 sourceDocs 新增一条
- 合并 → 创建含所有文档页面的合成文档

复用现有 `buildExportPdf` 的跨文档拷贝逻辑(它已支持从任意 sourceDoc 取页)。空白页用 pdf-lib 的 `addPage([w,h])`。

## 文件改动

### 1. Worker 层(protocol + engine + worker + client)

**`src/worker/protocol.ts`** - 新增类型:
- `WorkerRequestType` 加 `'createDocFromPages'`
- `CreateDocFromPagesPayload` - `{ targetDocId: string; pages: Array<{ sourceDocId: string; sourcePageIndex: number; rotation: 0|90|180|270 } | { blank: true; width: number; height: number }> }`
- 返回 `LoadDocResult`(pageCount + 尺寸),复用现有类型

**`src/worker/pdfEngine.ts`** - 新增 `buildDocFromPages(docs, pageSpecs)`:
- 类似 `buildExportPdf`,但支持 `blank` 规格(用 `addPage([w,h])`),返回新 PDFDocument(不 save)
- 现有 `buildExportPdf` 重构为调用 `buildDocFromPages` 后 `save()`,避免重复逻辑

**`src/worker/pdf.worker.ts`** - 新增 case `'createDocFromPages'`:
- 调用 `buildDocFromPages`,存入 `docs` Map(用 targetDocId),同时调 `loadPdfForRender` 让 pdf.js 也能渲染(需先 save 再 reload)
- 返回元数据

**`src/worker/workerClient.ts`** - 新增 `createDocFromPages(targetDocId, pages)`

### 2. Store 层(editorStore.ts) - 新增 5 个 action

**`insertBlankPage()`**:
- 确定尺寸(选中页的 width/height,或默认 595x842 A4)
- 确定位置(选中页之后;无选中则当前文档末尾)
- 调 `workerClient.createDocFromPages` 创建一个只含空白页的合成文档(blank-doc-N)
- 在 pages 数组对应位置插入新 Page(引用合成文档)
- 更新 sourceDocs(加合成文档,fileName 如"空白页")
- 推入 Command(undo 移除该 page + 合成文档)

**`duplicatePages(pageIds)`**:
- 取选中页的 sourceDocId+sourcePageIndex+rotation+尺寸
- 调 `createDocFromPages` 创建含这些页副本的合成文档
- 在每页原位之后插入副本 Page
- 推入 Command(undo 移除副本)

**`splitToNewDocument(pageIds)`**:
- 选中页原地拆分:调 `createDocFromPages` 用选中页创建新文档
- 从当前文档 pages 移除这些页,新增到新文档的 pages
- sourceDocs 新增一条
- 切换 activeDocId 到新文档
- 推入 Command(undo 还原)

**`saveSelectionAsDoc(pageIds)`**(另存为应用内文档):
- 与 split 类似,但不从原文档移除(复制到新文档)
- sourceDocs 新增,activeDocId 切换

**`mergeAllDocuments()`**:
- 取所有文档的非删除页,调 `createDocFromPages` 创建合并文档
- sourceDocs 新增"合并文档",activeDocId 切换
- 不动原文档(保留)

**CommandType 扩展**:`'insert' | 'duplicate' | 'split'`,并在 `redo()` 加对应分支(用 re-execute 策略,与现有 move/rotate 一致)。

### 3. UI 层

**`src/components/Toolbar/Toolbar.tsx`** - 新增编辑按钮组(在导出按钮后、spacer 前):
- 插入空白页 / 复制 / 旋转90° / 删除 / 拆分 / 合并 / 另存为新文档 / 导出选中页
- 全部 `disabled={selection.size === 0}`(合并除外,合并需 ≥2 文档)
- 复用现有 `.toolbar button` 样式

**`src/components/PageGrid/PageCard.tsx`** - 新增右键菜单:
- 复用 Sidebar 的 context-menu 模式(state + window listener + `.context-menu` CSS)
- `onContextMenu` 时:若该页未选中则先选中它(右键选中),再弹菜单
- 菜单项:旋转90° / 复制 / 删除 / 拆分到新文档 / 另存为新文档 / 导出选中页 / 插入空白页(在该页后)
- 菜单项根据 selection 状态启用/禁用

**`src/components/Sidebar/Sidebar.tsx`** - 文档右键菜单加"合并所有文档"选项

### 4. 测试(TDD)

- `tests/unit/insertBlankPage.test.ts` - 插入位置、尺寸、undo
- `tests/unit/duplicatePages.test.ts` - 副本位置、undo
- `tests/unit/splitDocument.test.ts` - 拆分后两文档页数、activeDocId 切换、undo
- `tests/unit/mergeDocuments.test.ts` - 合并后页数、原文档保留
- `tests/unit/pdfEngine.test.ts` - `buildDocFromPages` 含空白页 + 跨文档拷贝

## 不做的事(YAGNI)
- 不做剪贴板复制粘贴(复制=原地插入副本,已确认)
- 不做空白页尺寸选择弹窗(同尺寸,已确认)
- 不抽取共享 ContextMenu 组件(复用 Sidebar 内联模式,符合现有风格)
- 不给 insert/duplicate/split 的 redo 用 execute/undo 双方法(沿用 re-execute 策略)
